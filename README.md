# WebGIS Claude Skills

A reusable Claude Code skill system for Web GIS development, GIS automation, GeoAI, remote sensing, spatial databases, GeoServer, React mapping, testing, and deployment.

## Goals

- Make Claude Code behave like a disciplined Web GIS engineering assistant.
- Persist project state so interrupted sessions can resume from the last verified point.
- Provide reusable domain skills for React Web GIS, PostGIS, GeoServer, spatial APIs, remote sensing, GeoAI, testing, security, and DevOps.
- Keep project decisions, blockers, tasks, and changes traceable in Git.

## Planned skill layers

1. Project memory and resume protocol
2. Web GIS architecture
3. React + TypeScript Web GIS
4. MapLibre / map engine integration
5. PostGIS engineering
6. GeoServer engineering
7. Spatial API engineering
8. GIS data processing
9. Remote sensing / Google Earth Engine
10. GeoAI
11. Web GIS testing
12. Security
13. DevOps and deployment

## Status

Foundation phase: project memory system is being established.
