# Backend Decision Matrix

## Candidates
Python/FastAPI, Node.js/TypeScript, .NET, Java/Spring, Go.

## Rules
- Python: strong candidate for scientific/GIS/GeoAI processing and Python-native libraries.
- Node.js/TypeScript: strong candidate for TypeScript-heavy product APIs and real-time web workloads.
- .NET: evaluate for Microsoft-centric enterprise environments and strong typed application services.
- Java/Spring: evaluate for existing enterprise Java ecosystems and large service platforms.
- Go: evaluate for compact high-throughput services and operational simplicity.

Do not select a runtime without checking GIS library support, processing model, team skills, observability, deployment, and workload characteristics.
