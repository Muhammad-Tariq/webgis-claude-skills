# Web GIS Profile

## Use When
A browser-based application needs interactive maps, spatial layers, search, analysis, dashboards, editing, or GIS workflows.

## Core Skills
- project-memory
- project-orchestrator
- software-engineering
- webgis-architect
- webgis-frontend
- webgis-map-engine
- webgis-ux-design
- spatial-api
- postgis-engineering
- webgis-testing
- webgis-security
- gis-correctness
- performance-optimization
- documentation-engineering
- devops-deployment

## Conditional Skills
- geoserver-engineering — OGC services or GeoServer required
- gis-analytics — spatial analysis
- remote-sensing / google-earth-engine — imagery workflows
- geoai — ML/AI
- realtime-gis — live updates
- 3d-geospatial — 3D
- data-catalog-metadata — dataset discovery/catalog
- geocoding-routing — location search/routing

## Mandatory Gates
Architecture, data/CRS contract, UX, GIS correctness, testing, security, performance, deployment, documentation.
